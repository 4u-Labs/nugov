## 🏛️ Sobre o Projeto

O **NuGov** é uma aplicação web interativa de jornalismo de dados e controle social que transforma as planilhas públicas oficiais de gastos com o **Cartão de Pagamento do Governo Federal (CPGF / Cartão Corporativo)** de todos os presidentes do Brasil (2003 a 2026) em uma experiência idêntica a um aplicativo bancário moderno (**Nubank / Fintech**).

O projeto é inspirado no conceito de *Hiperlegibilidade* de dados públicos (popularizado pelo [Jmail](https://jmail.world/)), trazendo transparência real através de uma interface fluida, divertida e acessível.

---

## ⚡ Principais Recursos

* 💳 **Cartão Presidencial 3D Interativo:** Visualização com limite ilimitado bancado pelo contribuinte e alternância instantânea entre governos.
* 🏛️ **Seletor de Mandatos:**
  * **Lula 1 & 2** (2003–2010)
  * **Dilma Rousseff** (2011–2016)
  * **Michel Temer** (2016–2018)
  * **Jair Bolsonaro** (2019–2022)
  * **Lula 3** (2023–2026)
* 🧾 **Comprovantes com Notas Fiscais Reais:** Cada despesa conta com detalhes de CNPJ, cidade, horário, descrição e link para o documento público original escaneado.
* 💸 **Botão "Pagar com Imposto de Renda":** Simulação interativa e bem-humorada de quitação da fatura pelo contribuinte.
* ⚖️ **Calculadora do Cidadão:** Descubra quantos meses ou anos do seu salário seriam necessários para bancar cada lançamento do cartão corporativo.
* 🏆 **Top Recordes & Curiosidades:** As maiores compras em padarias, hotéis 5 estrelas e frotas de veículos.
* 🤖 **NuBot Presidencial:** Assistente interativo para consulta de dados públicos.
* 📲 **PWA Instalável:** Funciona offline e pode ser instalado no Android, iOS e Desktop.

## 📂 Fontes de Dados Públicas

Todos os dados apresentados no NuGov são exclusivamente de **natureza pública governamental**, respaldados pela Lei de Acesso à Informação (Lei nº 12.527/2011):
- **Portal da Transparência (CGU)**
- **Secretaria-Geral da Presidência da República**
- **Agência Fiquem Sabendo**
- **Base dos Dados**
